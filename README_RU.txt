DILEK ENGLISH — стартовый пакет

Файлы:
- index.html: текущий прототип приложения
- manifest.webmanifest: настройки установки как веб-приложения
- icon-192.png и icon-512.png: иконки
- sw.js: базовое кэширование оболочки для офлайн-открытия после первого посещения

ВАЖНО:
1. Этот пакет — PWA/веб-стартовый пакет, а не готовый подписанный .ipa.
2. Для установки по ссылке опубликуйте содержимое папки на HTTPS-хостинге.
3. На iPhone откройте опубликованную ссылку в Safari → Поделиться → На экран «Домой».
4. Для App Store нужна отдельная iOS-сборка, подпись, аккаунт разработчика, сведения о приватности и прохождение App Review.
5. Прогресс текущей версии хранится локально в браузере и не синхронизируется между устройствами.
